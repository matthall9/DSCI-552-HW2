# DSCI 552 Homework 2

This repository contains my solution to Homework 2 for DSCI 552.

- `Folds5x2_pp.xlsx`: Combined Cycle Power Plant dataset

- K-nearest neighbors regression

## Running the Notebook

Open the notebook in Google Colab or Jupyter Notebook and keep the Excel dataset in the same directory as the notebook.
